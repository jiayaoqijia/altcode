# v1.0 Agent Teams — Inspired by Claude Managed Agents

## What Claude Has That Altcode Should Adopt

### 1. Shared Task List with Dependencies (HIGH PRIORITY)
Claude's agent teams share a task list where tasks have states (pending/in-progress/completed)
and dependencies. When a task completes, blocked tasks auto-unblock.

**Altcode implementation:**
- `.altcode/workspace/{id}/tasks.json` — shared task list
- Each task: `{id, title, status, assignee, depends_on[], created_at}`
- Lifecycle manager checks dependencies before allowing agent to start a task
- TUI shows task progress alongside agent panes

### 2. Direct Agent-to-Agent Messaging (HIGH PRIORITY)
Claude teammates can message each other directly, not just report to the lead.

**Altcode implementation:**
- Shared mailbox in `.altcode/workspace/{id}/mailbox.json`
- Agents read new messages via context.md injection on each turn
- `/send <role> <message>` delivers to the mailbox
- Poll tick checks for new messages and injects into agent context

### 3. Plan Approval Gates (MEDIUM PRIORITY)
Claude teammates can work in "plan mode" — propose a plan, lead approves before execution.

**Altcode implementation:**
- `--plan-first` flag on workspace command
- Agents output plans to `.altcode/workspace/{id}/plans/{role}.md`
- Lifecycle waits for human approval before transitioning to implementation
- TUI shows plan + approve/reject buttons (y/n keys)

### 4. Quality Hooks (MEDIUM PRIORITY)
Claude has TeammateIdle, TaskCreated, TaskCompleted hooks.

**Altcode implementation:**
- Hooks in `.altcode/config.yaml`:
  ```yaml
  hooks:
    agent_idle: "run-tests.sh"
    task_completed: "lint-check.sh"
  ```
- Hook exit code 2 = reject (send feedback, keep working)

### 5. Self-Claiming Tasks (MEDIUM PRIORITY)
Claude teammates pick up the next unblocked task automatically.

**Altcode implementation:**
- After agent completes its initial task, check task list for unassigned tasks
- If found, inject new task prompt into agent via context.md
- Track assignments to prevent double-claiming (file lock)

## What Altcode Already Does Better

1. **Git worktree isolation** — built-in, not a flag
2. **CI auto-fix loop** — automated, not manual
3. **PR lifecycle state machine** — spawning→merged, with auto-merge
4. **Branch merging** — automated cherry-pick across agent branches
5. **Manager synthesis** — post-hoc LLM pass on all agent outputs
6. **GitHub API integration** — direct REST with token, not just gh CLI
7. **Process persistence** — agents survive terminal close (Setsid)
